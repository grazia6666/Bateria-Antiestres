# Batería Anti-Estrés

Proyecto de Sistemas Embebidos basado en ESP32.

## Características
- Modo Libre
- Modo Reflejos
- Modo Memoria
- Interfaz Web HTML/CSS/JavaScript
- Comunicación WebSocket
- OLED SSD1306
- LEDs WS2812B
- Sensores piezoeléctricos
- Ranking con LittleFS
